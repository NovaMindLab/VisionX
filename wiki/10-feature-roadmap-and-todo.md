# 📋 VisionX 智能眼镜与控制台 功能规划与 TODO 清单

本文档记录 **VisionX AI 智能眼镜**（硬件端 ESP32-S3 + 上位机 PC 控制台）的已完成成果与后续迭代规划。

---

## 🏆 已完成功能基线 (Completed Baseline)

- [x] **底层通信与硬件识别**：
  - 自动识别 Seeed Studio XIAO ESP32-S3 Sense 原生 USB CDC (`COM4` @ 115200bps / 460800bps)。
  - 支持 USB 设备热插拔动态监测与无缝重连。
  - DTR / RTS 信号线自动控制，软重启与设备信息指令互通。
- [x] **OV2640 摄像头拍照功能**：
  - ESP32 固件集成 OV2640 硬件驱动与 OPI PSRAM 双缓冲管理。
  - PC 端一键发送 `CAPTURE` 指令，极速回传并在控制台大图呈现与本地保存。
- [x] **实时连续视频流采集**：
  - ESP32 固件实现连续帧流采集，PC 端实现静默高速直通渲染（不卡顿终端日志）。
  - 支持 **12 ~ 18 FPS** 流畅视频流，实时动态显示实测帧率 (FPS) 与传输码率 (KB/s)。
  - 支持 QVGA (320x240) 与 SVGA (800x600) 动态切换。
- [x] **发布体积精简优化**：
  - 配置 `electronLanguages` 与 `afterPack` 自动化裁剪钩子，移除 53 个无用小语种。
  - 未压缩磁盘占用直降 **45.2 MB**，压缩后安装包直降至 **87.5 MB**（零报毒风险，不使用加壳）。
- [x] **GitHub 自动化发布系统**：
  - 编写 `auto_deploy/deploy.ps1` 与双击运行脚本 `deploy.bat`。
  - 自动完成环境校验、Vite 编译、Windows EXE 打包与 GitHub Release 极速上传。
  - 配置 `.github/workflows/release.yml` 云端 CI/CD 自动化流水线。
- [x] **差分增量升级体系 (Differential Auto-Update)**：
  - 集成 `electron-updater` 与 Blockmap 64KB 块哈希差分算法。
  - 软件启动 2.5 秒后自动静默自检 GitHub Releases；发现新版本弹窗提示。
  - 仅需下载几 MB 的变动数据块，支持一键“重启并完成安装”，毫秒级覆盖更新。

## 🚀 后续功能规划与待办清单 (Roadmap & TODOs)

### 模块一：多模态 AI 视觉感知与问答 (Vision AI Assistant) 【🌟 P0 核心】

> 赋予眼镜“AI 大脑”，让眼镜真正看懂、理解佩戴者眼前的世界。

- [ ] **多模态大模型 API 接入**：
  - [ ] 接入阿里通义千问视觉模型（`Qwen2-VL-7B-Instruct` / `Qwen-VL-Max`）。
  - [ ] 兼容 OpenAI `GPT-4o` / Google `Gemini 1.5 Pro` 多模态接口。
  - [ ] 支持本地离线多模态大模型（Ollama 框架下的 `LLaVA` / `MiniCPM-V`）。
- [ ] **AI 识图对话控制台**：
  - [ ] 在 `CameraView` 右侧新增侧边栏 **“AI 视觉助手”** 对话流面板。
  - [ ] 设置快捷键（空格键或快捷按钮）：自动截取当前第一视角画面，发送给大模型。
  - [ ] 预设快捷 Prompt 模式：
    - 🔍 **“眼前识别”**：详细描述当前场景、物体与环境。
    - 📖 **“文字朗读/翻译”**：自动提取眼前书籍、路标的文字并翻译为中文。
    - 🛠️ **“维修与排障向导”**：识别眼前电路板、机械结构并给出排查建议。
- [ ] **实时 HUD 与视觉辅助图层**：
  - [ ] 视频画面叠加中心十字准星、九宫格构图辅助线。
  - [ ] 前端轻量级人脸检测框与中心测距网格。
  - [ ] 实时 OCR 文本快速提取浮层（在视频中直接高亮识别到的文字区域）。

### 模块二：板载 PDM 麦克风与智能语音对讲 (Audio & Voice AI) 【🌟 P0 核心】

> 激活板载 MSM261D3526H1CPM 数字麦克风，完成视听双全的交互闭环。

- [ ] **数字麦克风底层采集 (ESP32-S3)**：
  - [ ] 编写 I2S PDM 采集驱动，采样率支持 16kHz / 16-bit 单声道语音。
  - [ ] 支持音频流实时打包回传给 PC 控制台。
- [ ] **动态音频示波器 (Audio Visualizer)**：
  - [ ] 激活控制台 `AudioView` 页面。
  - [ ] 利用 Web Audio API 绘制**动态音频波形图 (Waveform)**。
  - [ ] 绘制**傅里叶变换频谱图 (FFT Spectrum)**，实时监测周围声音分贝与环境噪音。
- [ ] **本地录音与试听**：
  - [ ] 支持一键点击 `[ 🎙️ 开始录音 ]` / `[ ⏹️ 停止录音 ]`。
  - [ ] 支持将眼镜收音结果保存为标准 `.wav` 文件并直接在电脑上回放。
- [ ] **端到端语音助手对讲闭环**：
  - [ ] 语音输入 ➔ 接入语音识别 (ASR，如阿里 FunASR / Whisper)。
  - [ ] 文字转交大语言模型生成思考结果。
  - [ ] 接入 Edge-TTS / 语音合成，电脑扬声器播报回复，实现类似 Ray-Ban Meta 的语音管家体验。

### 模块三：摄像头专业调参台 (Camera Control Studio) 【P1 重要】

> 针对智能眼镜外壳 3D 打印倒装、逆光曝光等真实佩戴痛点提供硬件级调节。

- [ ] **画面翻转与镜像校正**：
  - [ ] 水平镜像 (H-Mirror) 开关（解决自拍与第一视角方向反转）。
  - [ ] 垂直翻转 (V-Flip) 开关（解决 3D 外壳倒装镜头画面倒立问题）。
- [ ] **动态画质参数滑块**：
  - [ ] 亮度 (Brightness, -2 ~ +2)。
  - [ ] 对比度 (Contrast, -2 ~ +2)。
  - [ ] 饱和度 (Saturation, -2 ~ +2)。
  - [ ] 锐度 (Sharpness)。
- [ ] **曝光与白平衡预设**：
  - [ ] 自动曝光控制 (AEC) 开关与手动曝光补偿。
  - [ ] 自动白平衡 (AWB) 场景切换：自动、晴天日光、阴天、室内日光灯、白炽灯。
- [ ] **硬件滤镜特效**：
  - [ ] 一键切换：无滤镜、黑白滤镜、复古胶片、负片效果、绿野仙踪色调。

### 模块五：Wi-Fi 无线图传与电池功耗管理 (Wireless & Power) 【P2 演进】

> 彻底拔掉数据线，实现真正的无线便携佩戴。

- [ ] **图形化 Wi-Fi 智能配网面板 (Smart Provisioning)**：
  - [ ] 控制台增加“无线配网”选项卡：输入 Wi-Fi SSID 与密码。
  - [ ] 串口一键下发给 ESP32，ESP32 连上局域网后自动回传 IP 地址。
- [ ] **内网无线极速图传**：
  - [ ] ESP32 开启轻量 HTTP MJPEG 视频流服务。
  - [ ] 控制台支持无线拉流模式，拔掉 USB 线即可在整个局域网范围内实时无线预览视频。
- [ ] **锂电池电量健康监测**：
  - [ ] 采集 XIAO 板载锂电池分压电阻引脚电压（ADC）。
  - [ ] 实时换算并展示剩余电量百分比（100% ~ 0%），绘制电池放电曲线。
- [ ] **深度休眠 (Deep Sleep) 待机模式**：
  - [ ] 控制台发送 `SLEEP` 指令，ESP32 进入深度休眠（微安级功耗）。
  - [ ] 支持外置触控按键或抬手唤醒，实测电池续航翻倍。
