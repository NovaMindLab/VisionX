## 2. 硬件模块深入选型与设计考量

### 2.1 为什么选择 Seeed XIAO ESP32-S3 Sense？
1. **尺寸极致小巧**：仅拇指大小 (21mm x 17.5mm)，是市面上带摄像头和数字麦克风的最小 ESP32-S3 核心板。
2. **免除自行设计 PCB 的门槛**：主板分为下层（ESP32-S3 主控板，含锂电池充放电芯片）与上层扩展板（含数字 PDM 麦克风、DVP 摄像头排线接口及 TF 卡槽），采用专用的 B2B 连接器对插。
3. **自带电池管理电路**：主板背面自带锂电池焊盘（BAT+ 和 BAT-），直接插上 USB-C 线即可对 3.7V 锂电池以 500mA/100mA 电流充电，极大简化电路外围设计。

```
   Seeed Studio XIAO ESP32-S3 Sense 结构展开:
   +---------------------------------------+
   |   [OV2640/3660 摄像头]  [PDM 麦克风]    | <--- 顶部扩展感知板
   +---------------------------------------+
                     || (B2B 高密对插接口)
   +---------------------------------------+
   |   [ESP32-S3 (240MHz/8M PSRAM)]        | <--- 底部主控板
   |   [Type-C 接口]   [充电芯片]           |
   |   (背面: BAT+ / BAT- 焊盘)             |
   +---------------------------------------+
```

### 2.2 电池与续航方案选择
智能眼镜对重量极其敏感（整镜建议控制在 **40g~50g** 以内，单侧镜腿负重不超过 **18g**）。
*   **方案 A (推荐)：单侧 250mAh ~ 350mAh 锂电池 (重约 5~7g)**
    *   待机时长（BLE 保持连接，深睡/浅睡）：约 **6~12 小时**。
    *   全天候环境拾音：约 **3~5 小时**。
    *   连续拍照上传：约 **1~2 小时**（单次拍照耗时 < 1 秒，按每天主动抓拍 50~100 次计算，可支撑一整天使用）。
*   **方案 B (配重平衡双电池方案)**：
    *   左镜腿：放置 1x 200mAh 电池；
    *   右镜腿：放置主控板 + 1x 200mAh 电池（两电池并联，通过鼻梁上方细线互联）；
    *   优势：左右配重完全平衡，佩戴舒适不偏头。

### 2.3 音频输出扩展选型 (可选)
如果希望眼镜本身发声（无需佩戴手机耳机），可考虑在镜腿末端增加微型扬声器：
*   **方案 1：手机 / TWS 耳机直出（最推荐，零硬件负担）**
    *   AI 的回答声音通过手机端 App 播放，用户直接佩戴自己的 AirPods 或蓝牙耳机收听。
*   **方案 2：微型开方式音频 (Directional Audio)**
    *   增加一块微型 I2S 功放模块（MAX98357A，微型封装）+ 1506 规格微型腔体喇叭（放置在耳道斜上方）。

## 3. 制作必备工具清单

在开始制作前，请准备好以下工具：
1. **电烙铁与焊锡丝**（推荐细刀头/尖头，0.8mm 无铅低温焊锡丝）；
2. **万用表**（用于检测电池电压、通断测试防短路）；
3. **镊子与剥线钳**（用于处理 30AWG 极细飞线）；
4. **B-7000 / E-8000 电子胶水 或 瞬干胶**（固定镜头与外壳结构件）；
5. **热缩套管与热风枪/打火机**（防止裸露线头短路）；
6. **Type-C 数据线**（需具备数据传输功能，勿使用纯充电线）。
