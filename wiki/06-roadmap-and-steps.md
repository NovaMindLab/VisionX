# 06. 实战落地全流程路线图

本文档为开发者提供一份清晰的、从零开始打造 AI 智能眼镜的实战阶段规划与检验标准。

---

## 阶段规划概览

```
  Phase 1: 桌面 MVP 验证 (1~2天)
     │ ➔ 核心板烧录、相机/麦克风点亮、FastAPI 后端图文跑通
     ▼
  Phase 2: 移动端与无线联调 (3~5天)
     │ ➔ 手机 App 连接、BLE/Wi-Fi 数据中继、触控拍照 ➔ 语音播报端到端闭环
     ▼
  Phase 3: 硬件装配与穿戴实装 (1周)
     │ ➔ 3D 打印外壳、锂电池与开关焊接、上镜配平与视角校准
     ▼
  Phase 4: 性能调优与记忆进化 (持续迭代)
     │ ➔ 响应延迟压至 1.5 秒内、超低功耗睡眠、长期记忆与主动提醒
```

---

## 详细实施步骤

### 阶段一：桌面级 MVP 验证 (Day 1 ~ Day 2)
*目标：在不进行任何外壳焊接和组装的前提下，在电脑桌面上跑通全链路数据流。*

1. **硬件准备**：
   - 收到 Seeed XIAO ESP32-S3 Sense 核心板；
   - 安装 Arduino IDE 2.x 并配置好 ESP32 支持包与 `OPI PSRAM`。
2. **固件测试**：
   - 烧录示例 Camera Web Server 代码；
   - 打开串口监视器获取 IP 地址，在浏览器中查看摄像头实时图像，验证镜头对焦与感光。
3. **算法后端验证**：
   - 本地启动 [04. 软件与算法栈部署](./04-software-stack.md) 中的 FastAPI 脚本；
   - 使用 Postman 或 Python 脚本模拟上传一张照片，验证 Qwen2-VL 多模态大模型返回的解答与生成的语音。

> ✅ **阶段一验收标准**：通过代码触发一次拍摄，能在 2 秒内收到大模型针对该画面的中文语音解答。

---

### 阶段二：移动端与无线通信联调 (Day 3 ~ Day 5)
*目标：摆脱电脑数据线束缚，通过手机实现完全无线的便携交互。*

1. **网络与中继配置**：
   - 配置 ESP32 固件，使其开机自动连接手机个人热点；
   - 固件中加入触摸引脚监听，当手指接触 GPIO 1 铜箔时触发拍照上传。
2. **手机端中继运行**：
   - 编译运行 BasedHardware/omi 官方 Flutter 客户端（或使用轻量 Python/Web 客户端作为过渡）；
   - 绑定 ESP32 设备，打通“触摸 ➔ 抓拍 ➔ 上传 ➔ 手机扬声器自动朗读”的即时交互链路。

> ✅ **阶段二验收标准**：脱离电脑，在户外仅靠手机热点和板子，触摸引脚即可完成一次第一人称多模态问答。

---

### 阶段三：硬件装配与佩戴实装 (Day 6 ~ Day 10)
*目标：完成机械结构与电池供电，做成真正可舒适佩戴的智能眼镜。*

1. **结构件下单与打印**：
   - 在嘉立创/三维猴提交外挂盒或镜腿 3D 打印订单（材质选 SLA 8000 黑色树脂或 SLS 尼龙）；
2. **微型电路焊接**：
   - 将 3.7V 300mAh 锂电池、微型拨动开关、触控铜箔片焊接至 XIAO 主板；
   - 使用万用表测试无短路后，合上电源开关点亮设备。
3. **装配与校准**：
   - 将元器件嵌入外壳并用胶水固定摄像头镜头；
   - 夹在外挂眼镜腿上，戴上眼镜平视前方，微调镜头上下仰角与左右偏角，锁定视野中心。

> ✅ **阶段三验收标准**：整机重量控制在 45g 以内（外挂模块 < 18g），佩戴 1 小时无明显压迫感与剧烈发热。

---

### 阶段四：体验优化与进阶功能 (持续迭代)
*目标：让原型从“能用”进化为“好用、贴心”。*

1. **延迟极限压测**：
   - 采用流式多模态 API + 流式 TTS，实现首字发声时间缩短至 **1.2 秒以内**。
2. **功耗与续航调优**：
   - 加入空闲自动 Light Sleep 机制，将平时静态电流降至 15mA 以下，实现 8 小时以上待机。
3. **个人知识库与记忆流**：
   - 对接 Mem0 / Chroma 向量数据库，让智能眼镜记住你看到的名片、书籍、日程与物品位置。
