## 2. 创想 K2 切片软件 (Creality Print / OrcaSlicer) 推荐参数

| 切片参数项 | 推荐设置值 | 针对 K2 的优化说明 |
| :--- | :--- | :--- |
| **推荐耗材** | **PETG** (首选) 或 **PLA+ / PLA-CF** | **PETG** 韧性最好、耐汗水与油脂腐蚀、夹扣长期使用不易脆断 |
| **层高 (Layer Height)** | **0.12 mm** (精细) 或 **0.16 mm** | 首层 0.2mm，精细层高保证镜头孔圆润、卡扣公母槽配合顺畅 |
| **外墙圈数 (Wall Loops)** | **3 ~ 4 圈** | 增强微型外壳的机械强度与耐摔性 |
| **填充模式 (Infill Pattern)**| **螺旋体 (Gyroid)** | 40%~100%，受力均匀，振动抑制好 |
| **支撑类型 (Support)** | **树状支撑 (Tree Auto)** | 开启“仅在热床上有支撑”，支撑阈值角度设为 **35°**，一撕即掉 |
| **打印速度 (K2 高速优化)** | 外墙 100~120mm/s，内墙 200mm/s | 适当降低外墙速度可大幅提升表面光洁度 |
| **热床温度 (Bed Temp)** | PLA: 55°C / PETG: 75°C | 涂抹少许固体胶或使用 PEI 纹理板 |
| **喷嘴温度 (Nozzle Temp)**| PLA: 210~220°C / PETG: 235~245°C| 依据耗材厂家标定温度 |

## 4. 打印后处理与 5 分钟极速装配

1. **拆除微量支撑**：用小镊子剥除顶盖镜头孔处的树状支撑；
2. **放入硬件**：
   - 将 3.7V 微型锂电池平放入底盒下层；
   - 将 Seeed XIAO ESP32-S3 Sense 板子放入上层，让 Type-C 接口对准尾部充电开孔；
   - 将摄像头排线小角度折起，镜头朝前对准顶盖透光孔；
3. **合盖与固定**：将底盒与顶盖对准卡紧，插上 `Clip.stl` 夹扣；
4. **夹上眼镜**：夹在平时佩戴的眼镜右侧镜腿靠近铰链处，调整镜头水平视角即可。
