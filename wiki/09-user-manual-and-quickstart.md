# 09. 实机操作与日常使用手册 (User Manual)

本文档面向最终使用者与开发者，详细说明智能眼镜组装完成后的开机、配对绑定、核心功能操作方式、充电维护及常见问题排查。

---

## 1. 快速开机与配对指南 (首次使用)

```
 [ 打开眼镜电源 ] ──────► [ 手机打开 App / 开启蓝牙 ] ──────► [ 自动配网绑定 ] ──────► [ 戴上眼镜开启体验 ]
 (拨动开关 ON)             (搜索 VisionX / Omi 设备)          (同步热点与Wi-Fi)        (轻触镜腿即问即答)
```

### 步骤 1：开机与状态指示
1. 拨动外壳侧面的微型电源开关至 `ON` 位置；
2. **指示灯状态说明**：
   * **蓝灯慢闪**：等待手机蓝牙 (BLE) 连接中；
   * **蓝灯常亮 2 秒后熄灭**：已成功连接手机 App；
   * **白灯/绿灯瞬时亮起**：摄像头正在抓拍（保护隐私指示）。

### 步骤 2：手机 App 连接与 Wi-Fi 配网
1. 打开手机蓝牙与 GPS 定位，启动 VisionX / Omi Companion App；
2. 在 App 设备列表点击 **“扫描并连接 VisionX”**；
3. 连接成功后，App 会通过 BLE 自动下发当前手机热点（或家庭 Wi-Fi）的 SSID 与密码给眼镜，眼镜完成高速 Wi-Fi 通道建立。

## 2. 三大核心功能与日常操作方式

### 💡 功能一：第一人称视界问答 (Touch & Ask VQA)
当你看到眼前不认识的物体、外文菜单、植物、账单或风景想要提问时：

1. **触发抓拍**：用手指轻触镜腿上的触控感应区（或轻按外壳触控点）；
2. **状态提示**：前置隐私指示灯亮起约 0.5 秒，眼镜瞬间完成画面捕捉并上传至手机端后端；
3. **语音提问与回答**：
   * 方式 A（图文提问）：通过手机端输入问题（如“帮我算一下这顿饭总共多少钱”）；
   * 方式 B（语音提问）：通过连接的蓝牙耳机或手机麦克风直接说出你的问题；
4. **收听解答**：大模型（Qwen2-VL / GPT-4o）在 1.5 秒内通过 TTS 将中文语音答案推送至你的耳机或手机播放。

---

### 🧠 功能二：全天候环境对话记忆流 (Ambient Memory Recall)
智能眼镜的数字 PDM 麦克风可在后台以超低功耗工作，帮助你构建专属“第二大脑”：

1. **日常佩戴**：在开会、上课、与朋友交谈时正常佩戴眼镜；
2. **实时转录**：语音数据经由 BLE 流式传输至后端 ASR（FunASR / SenseVoice），自动过滤环境杂音与静音段；
3. **智能提炼与记忆归档**：
   * 后端 Memory Agent 每隔 15 分钟自动提炼核心事项（待办 Task、重要决议、人名信息、约定时间）；
   * 自动向量化存入本地知识库（Chroma / Mem0）；
4. **随时唤醒检索**：
   * 打开 App 询问：“我今天上午和李总讨论了哪些方案细节？”
   * AI 会调取上午相关的环境对话记忆并生成结构化回答。

---

### 📸 功能三：第一人称生活延时日志 (Life Logging)
* 可在手机 App 中开启 **“间隔抓拍日志”** 模式（如每 5 分钟或 10 分钟自动记录一帧画面）；
* 自动生成当天的图文生活日记与旅行时间轴，所有照片均保存在本地，兼顾隐私与回忆。

## 3. 充电与电池日常维护

```
                [ USB Type-C 充电线 ]
                          │
                          ▼
             ┌─────────────────────────┐
             │  底盒尾部 Type-C 充电口  │
             └────────────┬────────────┘
                          │
           ┌──────────────┴──────────────┐
           ▼                             ▼
   [ 红色 LED 亮起 ]             [ 绿色/蓝灯亮起 ]
     正在充电中                    电池已充满 (约45分钟)
```

*   **充电方式**：使用任意标准 5V 手机充电器或电脑 USB 口连接眼镜底盒尾部的 Type-C 接口；
*   **充电时间**：内置 300mAh 微型锂电池从 0% 充至 100% 约需 **45 分钟**；
*   **续航参考**：
    *   纯待机：**8 ~ 12 小时**；
    *   连续主动拍照问答：约可支持 **100 ~ 150 次**；
    *   全天候连续录音：**3 ~ 5 小时**；
*   **保养建议**：长时间不用时请将物理开关拨至 `OFF` 断电，建议每 2 个月充一次电以延长锂电池寿命。

## 4. 常见问题排查 (Troubleshooting FAQ)

### Q1：手机 App 搜不到眼镜蓝牙？
1. 检查物理电源开关是否拨至 `ON`；
2. 用 Type-C 线插上充电，确认是否电量耗尽；
3. 检查是否有其他手机已被占用连接（ESP32 BLE 默认同时仅支持连接一台主设备）。

### Q2：轻触镜腿后没有拍照动作？
1. 检查触摸引脚（GPIO 1）连接的铜箔片是否与手指接触良好；
2. 确认手机热点是否开启（2.4GHz 频段，ESP32-S3 不支持纯 5GHz Wi-Fi 频段）。

### Q3：AI 识别出来的物体不准确或画面模糊？
1. 检查 3D 打印顶盖镜头孔是否有塑料毛刺遮挡；
2. 逆时针/顺时针轻轻旋转 OV2640/3660 镜头的螺纹对焦环，将清晰焦距调节至人眼前方 0.5米 ~ 3米 正常视线距离。
