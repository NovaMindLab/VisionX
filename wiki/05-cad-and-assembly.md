# 05. 结构设计与 3D 打印装配指南

本文档介绍智能眼镜的物理外壳设计、3D 打印材质工艺选型、电路接线图以及完整的装配与调试步骤。

---

## 1. 两种硬件结构形态选型

在制作原型时，开发者通常有两种结构路线可供选择：

```
形态对比：
┌──────────────────────────────────────┐     ┌──────────────────────────────────────┐
│       方案 A：外挂夹扣式 (Clip-on)    │     │       方案 B：一体化镜框 (Integrated)  │
│                                      │     │                                      │
│   [ 任意现有眼镜 ] ─── [ 夹扣主板盒 ]  │     │   [ 3D 打印整镜架 (左右镜腿藏元器件) ]│
│                                      │     │                                      │
│  - 制作周期：1~2 小时                │     │  - 制作周期：1~2 周                  │
│  - 难度：⭐ (极简)                   │     │  - 难度：⭐⭐⭐⭐ (需精细布线与装配)   │
│  - 优点：适配自己有度数的眼镜        │     │  - 优点：外观美观、重量均匀分布      │
└──────────────────────────────────────┘     └──────────────────────────────────────┘
```

*   **新手推荐**：先从 **方案 A (外挂夹扣)** 入手，打通整套软硬件链路并验证算法后，再升级为 **方案 B (一体化镜架)**。

## 2. 3D 打印材质与工艺推荐

| 工艺与材料 | 表面质感 | 强度与耐热 | 推荐制作部位 | 打印成本预估 |
| :--- | :--- | :--- | :--- | :--- |
| **SLA 光敏树脂 (高韧性 8000/8111，黑色哑光喷漆)** | 表面极其细腻光滑，接近注塑级质感 | 韧性良好，耐温约 55°C | 主板外壳、夹扣卡扣、装饰面盖 | ¥15 ~ ¥30 |
| **SLS 尼龙 (PA12 / 玻纤尼龙)** | 微磨砂质感，极轻 | 机械强度极高，耐温 120°C，耐摔耐折 | 一体式镜腿、铰链连接件、鼻托 | ¥30 ~ ¥60 |
| **FDM (PETG / PLA+)** | 表面有明显层纹 | 强度一般，受热易软化 | 桌面验证打样（个人 3D 打印机自打） | ¥2 ~ ¥5 |

> 💡 **设计关键规范**：
> 1. 外壳壁厚建议保持在 **1.2mm ~ 1.5mm** 之间；
> 2. 摄像头开孔需预留 **FOV 视场角倒角**（倒角 >= 45°），避免外壳遮挡镜头视野边缘产生黑边；
> 3. ESP32-S3 芯片发热部位应在侧面预留 **0.8mm 隐蔽散热微孔**。

```
                +------------------------------------+
                |       微型聚合物锂电池 3.7V         |

                                  |
                                  ▼
                       +----------+-----------+
                       |   BAT+ (XIAO 背面焊盘)|
                       |                      |
                       | XIAO ESP32-S3 Sense  |
                       |                      |
                       |   BAT- (XIAO 背面焊盘)|
                       +----------+-----------+
                                  ▲
                                  | (负极 Black)
                +-----------------+------------------+
                |          电池负极共地              |
                +------------------------------------+
```

### 3.2 辅助元件接线
1. **触控按键 (Touch Sensor)**：
   * 铜箔触摸片引出一根细飞线 ➔ 连接 XIAO S3 的 **GPIO 1 (Touch 1)** 或 **GPIO 2 (Touch 2)**。
2. **隐私指示 LED (Recording Indicator)**：
   * **GPIO 21** ➔ **330Ω 限流电阻** ➔ **LED 正极**；
   * **LED 负极** ➔ **GND**。

## 4. 详细组装步骤

### 第一步：元器件预检与刷写测试
1. 在焊接任何电池前，先用 Type-C 线将 XIAO ESP32-S3 Sense 连接电脑；
2. 烧录测试固件，确认串口输出正常、摄像头能正常抓图。

### 第二步：飞线焊接
1. 将 30AWG 特软硅胶线剪至合适长度（约 3~5cm）；
2. 烙铁温度调至 **320°C ~ 350°C**，动作轻快，避免长时间加热损坏主板微型焊盘；
3. 将电池正极焊接至拨动开关第一引脚，开关第二引脚焊接至主板背面 `BAT+` 焊盘；
4. 将电池负极焊接至主板背面 `BAT-` 焊盘；
5. 用热缩管包裹开关裸露引脚，防止短路。

### 第三步：外壳嵌入与固定
1. 将摄像头排线小心弯折，按设计角度卡入 3D 打印外壳的镜头限位槽；
2. 用微量 **B-7000 胶水** 点在镜头底座边缘固定（切勿让胶水污染镜头表面透镜）；
3. 将主板与扩展板紧密贴合放入主仓；
4. 将电池平整放入电池仓，合上外壳上盖，用 M1.4 微型沉头螺丝固定或卡扣卡紧。

### 第四步：装配上镜与角度校准
1. 将外壳卡扣夹在眼镜右侧镜腿靠近铰链处；
2. 戴上眼镜，在手机端打开实时预览画面；
3. 微调摄像头垂直与水平朝向，确保抓拍画面中心与人眼平视视线方向一致；
4. 确认无误后紧固外壳固定结构。
