# 07. 进阶拓展与演进方向

当你完成了基础版智能眼镜（音频录制 + 摄像头拍照 + 云端大模型 + 语音播报）后，可参考本章内容进行更高级的硬件与算法拓展。

## 1. 增加微型光学显示 (HUD / 抬头显示)

如果希望眼镜不仅能“发声”，还能在眼前直接看到 AI 回答的文字、实时翻译字幕或导航箭头，可引入光学显示方案：

### 推荐 DIY HUD 方案：0.39 英寸 Micro-OLED + 棱镜模组
*   **驱动芯片**：SSD1306 / ST7789 驱动控制；
*   **接口**：使用 ESP32-S3 剩余的 SPI 引脚（SCLK, MOSI, CS, DC, RES）；
*   **显示内容**：在右眼前方约 2 米处呈现一块虚拟的 20 英寸半透明单色/彩色显示画面，实时滚动显示 ASR 转录文字与 AI 简短回复。

## 2. 镜腿骨传导与开放式立体声音频

若想摆脱外部手机/蓝牙耳机，实现一体化声音收听：

1. **硬件选型**：
   * 功放芯片：**MAX98357A** (I2S 数字功放，超小体积，直接将 ESP32 I2S 数字音频转为扬声器驱动信号)；
   * 发声单元：
     * **方案 A (开放式定向微型喇叭)**：1506 规格双磁腔体喇叭，放置在镜腿下缘，声音对准耳道，漏音小且音质清晰；
     * **方案 B (骨传导振子)**：16mm 扁平骨传导振子，贴紧耳后乳突骨。
2. **引脚连接**：
   * ESP32 I2S BCLK ➔ MAX98357A BCLK
   * ESP32 I2S LRCK ➔ MAX98357A LRCLK
   * ESP32 I2S DOUT ➔ MAX98357A DIN

## 3. 端侧轻量级 AI (离线唤醒词与姿态手势)

利用 ESP32-S3 的双核 Xtensa LX7 矢量指令集（Vector Extension），可以在端侧运行轻量级神经网络：

### 3.1 离线本地唤醒词 (ESP-SR)
*   **作用**：无需云端持续耗电监听，在本地芯片运行 300KB 的离线唤醒模型（如听到“小智你好”或“Take a look”后才唤醒摄像头与 Wi-Fi）。
*   **框架**：乐鑫官方 **ESP-SR (WakeNet / MultiNet)**。

### 3.2 头部姿态与手势识别 (IMU 6 轴陀螺仪)
*   **硬件**：在镜腿内增加一颗 **MPU6050 / LSM6DSO** 超低功耗 6 轴加速度计陀螺仪（I2C 通信）；
*   **交互定义**：
    *   **点头 (Nod)**：确认操作 / 接听来电 / 接受 AI 建议；
    *   **摇头 (Shake)**：取消操作 / 停止当前 TTS 播报；
    *   **双击镜腿 (Double Tap)**：快速抓拍。

## 4. 极致功耗与全天候续航优化策略

若要实现类似 Ray-Ban Meta 的全天候佩戴（8~12 小时综合续航）：

| 运行状态 | 芯片与外设工作模式 | 电流消耗 (mA) | 优化策略 |
| :--- | :--- | :--- | :--- |
| **深度待机 (Deep Sleep)** | CPU 关断，仅 RTC 与 ULP 协处理器 / 触摸检测工作 | **< 0.15 mA** | 眼镜摘下静置 3 分钟自动进入深度休眠 |
| **轻度待机 (Light Sleep)** | CPU 降频至 40MHz，维持 BLE 广播心跳 | **约 2~4 mA** | 佩戴中未触发交互时的默认状态 |
| **环境拾音 (Audio Stream)** | CPU 160MHz，PDM 麦克风工作，BLE 连续发包 | **约 18~25 mA** | 采用 VAD (静音检测)，无声音时暂停 BLE 发送 |
| **图像抓拍 (Photo Snap)** | CPU 240MHz，摄像头瞬时上电 ➔ 采图 ➔ Wi-Fi 突发上传 ➔ 关闭 Wi-Fi | **约 180~320 mA (持续仅 0.5 秒)** | 突发传输完毕立刻将 Wi-Fi 切换为 Modem-Sleep |
