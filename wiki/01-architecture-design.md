# 01. 系统架构与技术选型

本章详细介绍基于 `BasedHardware/omi` 架构体系的 AI 智能眼镜整体系统架构、数据流向、通信协议设计及核心设计权衡。

---

## 1. 整体架构图 (端 - 边 - 云)

AI 智能眼镜的核心设计哲学在于**将重型计算（大语言模型推理、视觉多模态理解、向量记忆检索）上移至云端/本地服务器，将高频交互与低功耗中继置于移动端（手机），而眼镜端专注于第一人称数据采集与极简交互**。

## 2. 关键通信协议选型

智能眼镜在无线传输方面面临**功耗**与**带宽**的天然矛盾。Omi 体系对两种主要数据流进行了协议分离：

### 2.1 音频数据流 (低功耗连续流)
*   **通信媒介**：Bluetooth Low Energy (BLE 5.0 GATT)
*   **传输格式**：
    *   方案 A：16kHz 16-bit 单声道 PCM 原始流（分包发送，每包约 200~240 字节，需协商 MTU >= 247）。
    *   方案 B（推荐）：Opus 编码音频帧（大幅降低 BLE 吞吐压力与功耗，延长待机）。
*   **功耗表现**：连续采集并 BLE 广播时芯片功耗仅约 **15~25mA**。

### 2.2 视觉图像流 (按需或定时间歇流)
*   **传输挑战**：一帧 800x600 的 JPEG 图片约 20KB~50KB，若直接使用 BLE 传输耗时约 1~3 秒且极度消耗 BLE 队列。
*   **传输方案对比**：
    1.  **Wi-Fi 模式（推荐，与 Omi 默认一致）**：
        *   ESP32-S3 连接手机热点或家庭 Wi-Fi，通过 HTTP POST / TCP 直接向手机或后端推送 JPEG。传输时间 < 150ms。
        *   不拍照时保持 Wi-Fi Modem-Sleep 状态以节能。
    2.  **BLE 多包分片分发 (Fallback)**：
        *   若无 Wi-Fi 连接，固件将 JPEG 分片为 240 字节包通过 BLE Characteristic 连续发送，手机端拼接校验。

## 3. 核心交互模式与数据流

### 模式 A：第一人称视觉问答 (Visual QA on Demand)
1. **用户触发**：
   * 方式一：轻触镜腿触控区域 / 物理按键。
   * 方式二：语音唤醒（如“看下眼前这个是什么 / 翻译这篇菜单”）。
2. **硬件动作**：
   * 前置隐私 LED 闪烁（提示正在拍摄）；
   * 摄像头上电初始化，抓拍一帧清晰 JPEG（800x600 或 1600x1200）；
   * 将图片推送到手机 App。
3. **模型处理**：
   * 手机将“用户语音问题 + 当前抓拍图片”打包发送至后端多模态 LLM；
   * 模型推理生成解答，并通过 TTS 将声音推送到手机扬声器 / 骨传导耳机播放。

### 模式 B：环境记忆流与全天候转写 (Ambient Memory Recall)
1. 麦克风全天候低占空比监听环境对话；
2. ASR 实时流式转录文字，过滤静音片段；
3. 后端定期运行后台摘要提取（Summary Agent），将事件、人名、日程提取并存入向量记忆库；
4. 用户后续可随时提问（如：“我今天上午和张经理聊了什么关于预算的事？”）。

## 4. 行业主流方案对比分析

| 方案 / 产品 | 主控与连接 | 视觉能力 | 显示方案 | 核心优势 | 开源/DIY 可行性 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **BasedHardware Omi / OpenGlass** | ESP32-S3 + BLE/Wi-Fi | OV2640/3660 (抓拍) | 无 (纯音频+手机端UI) | 全开源、模块化、极低门槛、社区活跃 | ⭐⭐⭐⭐⭐ (极高) |
| **Ray-Ban Meta** | 高通 Snapdragon AR1 Gen1 | 1200万像素 + 1080p 录像 | 无 (开方式扬声器) | 外观极致、音质优秀、续航与算力顶级 | ❌ 封闭商业闭源 |
| **Brilliant Labs Frame** | nRF52840 + FPGA | 彩色相机 (低帧率) | 单目 Micro-OLED 棱镜显示 | 极轻 (39g)、支持 HUD 显示、全开源 | ⭐⭐⭐ (硬件门槛较高) |
| **Even Realities G1** | 双芯片 + 超低功耗 BLE | 无摄像头 (纯文本/通知) | 双目绿色 Micro-LED 光波导 | 日常眼镜外观、超长续航 | ❌ 商业闭源 |

> **结论**：以 **Seeed XIAO ESP32-S3 Sense + Omi** 为蓝本是当前个人开发者和初创团队制作 **AI 多模态智能眼镜原型（Ray-Ban Meta 平替）** 的最佳开源技术路线。
